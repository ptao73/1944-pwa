# 🛩️ 1944: Pacific Strike 3D (PWA)

> 经典街机空战《1944》的伪 3D 重制版 —— 追尾视角、透视纵深、无需安装、离线可玩。

**在线游玩：https://ptao73.github.io/1944-pwa/**
（俯视 2D 经典版保留在 [classic.html](https://ptao73.github.io/1944-pwa/classic.html)）

## ✨ 特性（v5 · 3D 重制）
- ✅ **追尾视角伪 3D**：透视投影引擎（`screen = center + world × FOV/(FOV+z)`），画家算法按纵深排序渲染
- ✅ **纵深世界**：海面波纹向镜头滚动、岛屿/云层由远及近掠过、落日余晖地平线
- ✅ **3D 空战**：敌机从地平线深处来袭，由小变大；准星指示弹道；曳光弹射向纵深
- ✅ **Boss 战**：每 3 关遭遇巨型四发轰炸机，瞄准三连发 + 环形弹幕，半血狂暴
- ✅ **武器升级**：拾取 `P` 提升火力（4 级），中弹降 1 级；`W` 僚机环绕；`♥` 补生命
- ✅ **Loop 大招**：能量充满后清屏，对 Boss 固定伤害
- ✅ **合成音效**：WebAudio 实时合成，零音频素材，可静音
- ✅ **机体细节**：滚转侧倾、旋转螺旋桨、引擎喷焰、翼尖航灯、玻璃座舱、3D 粒子爆炸
- ✅ **PWA**：离线游玩、添加到主屏幕；**零依赖**单 HTML 文件，Canvas 2D 渲染

## ▶️ 操作方式
**触屏**（手机/平板）：
- 手指拖动 → 飞机跟随机动，自动开火；准星对准敌机即可命中
- 右下角 `LOOP` 按钮 → 清屏大招；左下角 🔊 → 静音

**键盘**（桌面）：
| 按键 | 功能 |
|------|------|
| `← → ↑ ↓` / `WASD` | 机动 |
| `L` | Loop 大招 |
| `P` | 暂停 |
| `M` | 静音 |
| `Enter` / `Space` | 开始 |

## 🚀 本地运行
```bash
cd 1944-pwa
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 📦 部署到 GitHub Pages
仓库 Settings → Pages → Source 选 `main / (root)`。所有资源相对路径，子路径部署开箱即用。
